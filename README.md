# XON Media Ltd

Static carbon copy of [xonmedia.ltd](https://www.xonmedia.ltd/) for Cloudflare Pages.

## Local preview

```bash
npm install
npm run dev
```

## Deploy

```bash
npx wrangler login   # use info@xonmedia.ltd
npm run deploy
```

Custom domain is not attached yet — use the `*.pages.dev` URL from deploy output.

## Layout

- `public/` — mirrored static site
- `brand/logo/` — logo pack for the repo
